# 量表滚动与访视更正

量表复现：在固定高度、外层隐藏溢出、内部表单可滚动的容器内，连续点击单选题并回车跳题，修复前 header 顶部变为 -1309px，修复后保持 0。隐藏单选框改为相对所属选项定位；键盘跳题只调整最近的可滚动内容容器，移除跨祖先的 scrollIntoView。沿用原有尺寸、列数、间距和页面框架。共享逻辑覆盖 DTSQ、PHQ-9、GAD-7 等自定义单选题，EQ-5D 使用同一局部滚动函数。

草稿录入员/中心管理员/最高权限账号可更正访视日期，保留已有表单和当前未保存输入。后端拒绝空日期和同患者同日期中间采集冲突。已提交及之后状态继续使用原撤回/退回流程。

删除入口需二次确认，删除草稿及其表单，保留患者和其他访视，写入审计。有费用照片、不良事件或质疑的访视拒绝直接删除，提示更正日期；费用照片可先按原功能逐张删除。请求按中心隔离，质控账号不具有删除权限。

验证：滚动复现、原键盘回归、日期更正保留未保存内容、取消删除、删除后刷新；后端覆盖日期冲突、空日期、权限、非草稿限制、关联表单清理、重建同类型访视、图片保护。无需数据库迁移，需同步发布前后端。
