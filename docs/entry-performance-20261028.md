# 录入操作与响应优化（2026-10-28）

## 已确认交互

- 输入框按 Enter 进入当前页下一项，跳过隐藏、禁用、只读字段，不自动提交。
- 中文输入法确认候选字时不跳格。多行文本保留 Enter 换行，Ctrl+Enter 跳下一项。
- EQ-5D、PHQ-9、GAD-7 未答题默认聚焦第一项；DTSQ 聚焦从左向右第五项。有历史答案时聚焦原答案。
- 聚焦不勾选、不生成答案；Enter 确认当前选项后进入下一题。方向键可调整选项。最后一项只移到保存按钮，不自动保存。
- 绿色情况提示统一放大，支持关闭和多条提示排列。

## 保存及操作等待

首次保存仍发送各表单。当前访视中仅缓存已经成功保存的内容签名，后续相同内容不重复发送。失败项不缓存，重试不重复发送前面已成功的表单。切换访视、重新加载清空缓存，保存期间继续输入仍保留“有修改待保存”。

保存、提交、图片上传/删除、撤回/退回、审核/签名/锁定显示处理提示并阻止重复点击；提交后的按钮保持只读。保存期间新增修改会要求再次提交，避免提交旧内容。

## 图片

- 原图不压缩、不改写。上传显示百分比，100% 后显示服务器校验保存中；多图仍逐张上传。
- 网络中断/超时不自动重试，提示先刷新列表确认结果，避免重复上传。
- 列表使用最长边 640 像素的缩略图，最多三个预览请求同时执行；打开大图才下载原图。
- 新增鉴权接口 `GET /api/patients/{patient_id}/images/{image_id}/thumbnail`，沿用中心访问边界和审计，不提供公共图片地址，响应禁止缓存。
- 缩略图在内存生成，不增加磁盘副本；关闭大图释放临时资源。

## 验证与范围

本地浏览器使用模拟患者及请求，不能代替医院网络实测。同一表单每请求模拟 60ms 延迟：原来重复保存两次发 12 次请求约 783ms，改后重复保存为 0 次请求约 2ms；首次保存仍约 380ms。

验证覆盖量表焦点不作答、已有答案保留、中文输入法、多行文字、重复提交、只读状态、失败重试、保存中继续修改、图片缩略图/原图按需请求。图片接口验证跨中心拒绝、质控可查看、缩略图尺寸/体积、原图字节不变、删除后不可访问。

上线需同步更新前后端，无数据库迁移。静态资源版本已更新。上线后用测试患者确认键盘录入、照片上传/查看/删除、保存与撤回。如果仍慢，需结合具体时间、图片大小和浏览器请求耗时检查网络、代理及服务器；本轮未证实线上卡顿只有一个原因，也未改变原图上传字节数。
