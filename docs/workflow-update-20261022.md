# EDC 流程优化：2026-10-22

## 本轮规则

| 功能 | 本中心录入员 | 本中心质控员 | 最高权限账号 |
|---|---|---|---|
| 查看患者汉字姓名、访视、费用图片 | 本中心 | 本中心 | 所有中心 |
| 新建患者、填写草稿、提交、签名 | 可以 | 不可以 | 可以 |
| 提质疑、审核、关闭质疑 | 不可以 | 可以 | 可以 |
| 锁定已签名访视 | 不可以 | 可以 | 可以 |
| 解锁或将已审核访视退回更正 | 不可以 | 不可以 | 可以 |
| 设置待追踪／已完成追踪 | 本中心 | 本中心 | 所有中心 |
| 分析数据导出 | 本中心，脱敏 | 本中心，脱敏 | 可选中心，脱敏 |

医大二院的普通录入员、质控员也只访问本院。原有中心管理员兼容保留，但不授予跨中心权限；新日常邀请码仅生成录入员、质控员两类。

正常访视流程：录入员保存草稿 → 提交审核 → 质控处理质疑并审核通过 → 录入员签名 → 本中心质控锁定。审核通过与锁定是两个步骤。待审核误提交仍可由录入员填写原因撤回；已审核或锁定须最高权限账号退回／解锁，并重新审核签名。

## 页面与操作

- 患者管理显示当前权限范围内全部患者，支持中心、追踪标签、编号／首字母筛选与分页。加载失败明确显示错误，不能当作患者已删除。
- 已录入名单仅包含至少有一次访视审核通过的患者（包括已签名、已锁定）。后续访视为草稿不影响入选；只有待审核访视或知情同意不入选。筛选在后端分页之前执行。
- 患者卡片右上角分别显示追踪标签、最近访视状态、是否已有审核通过访视及待处理质疑。追踪标签人工设置，与审核状态独立。
- 患者管理、已录入名单、质控详情打开浏览器新标签页。原页筛选保持；患者标识在新标签页地址中，刷新后仍定位该患者。登录凭据不写入地址。
- 姓名在患者列表、访视和质控列表显示汉字；缺失姓名时回退首字母。基本信息页可维护姓名。质控员的身份证、电话仍按原规则掩码显示。
- 每页显示已填项目数、待保存／已保存／只读／已锁定。圆点提示该页是否已有填写；项目数不代表质控通过，也不构成新的必填规则。关闭有未保存修改的标签页会有浏览器提示。
- 药剂名手动输入，治疗类型及给药途径保留常用选项和其他自填。复制同一患者按访视日期最近的上一次访视全部药物；同日按创建ID确定先后。无历史记录时提示；本次非空先确认替换。停用状态和结束日期一起复制，复制内容仅随本次草稿保存，不改历史。
- 费用图片提供缩略图、点击大图和单张确认删除。删除成功后移除记录及原文件，无回收站；失败不显示成功。访视照片只允许在草稿状态由录入人员修改；质控可查看，不可上传删除。图片删除保留操作审计，不保留应用内可恢复副本；既有运维备份不由该按钮改写。
- 知情同意保留独立模块和纸质扫描件上传；不增加必须上传才可提交的限制。本次图片删除和缩略图针对费用图片。
- XLSX、CSV分析数据导出固定采用现有姓名／身份证／电话掩码。包括最高权限账号，均拒绝明文导出参数。原始扫描件下载不做OCR或图片涂抹。

## 部署准备

新增字段 `patients.tracking_status`，默认 `pending`。迁移只新增字段，重复执行安全，保留患者和访视。生产环境必须先完成迁移再启动新版程序。

已提供 `deploy/update-workflow-20261022.sh`：沿用运行容器的部署配置和持久化卷，构建新镜像，停止写入，备份数据库和照片，校验原数据指纹，执行增量迁移并启动。失败保持入口停止，并输出回退方式。回退只切换应用镜像，保留数据库和追踪字段；旧页面不展示追踪字段。脚本依赖现有 MySQL 8.4 与前一版图片功能环境。

在已更新的服务器运行以下命令可为所有启用中心（含主中心）生成／复用录入、质控各一个有效单次邀请码；默认有效期7天。一人领取一个，注册后失效；再次运行补足未使用数量，不重置已注册账号。

```sh
docker exec edc-prod-backend python scripts/provision_study_invites.py --admin-username '实际最高权限用户名'
```

`--count N` 表示每中心每角色准备N个未使用邀请码。输出包含邀请码，应仅由项目负责人分发给对应人员。本轮未操作线上账号或线上数据库。

## 验收重点

1. 主中心录入员、质控员各自登录，看不到其他中心患者；最高权限账号能按中心筛选。分中心同理。
2. 超过一页的患者列表能正常翻页；加载失败可重试。已录入名单不含仅提交未审核者；已审核基线加后续草稿者仍在名单。
3. 同时打开两位患者，各自刷新和填写不串患者，原列表页保持筛选。
4. 新访视复制上次用药、取消替换、确认替换及保存；回看上次访视，记录不变。
5. 质控锁定本中心已签名访视；未签名、跨中心、录入员锁定均被拒绝。
6. 上传真实费用图片后可预览，确认单张删除后刷新仍不存在；待审核时先撤回才能改访视图片。
7. 追踪标签保存后刷新仍存在；修改标签不改变访视审核状态。所有角色导出均掩码。

## 暂缓与未复现

合并症强制联动、核心化验缺失拦截及缺失化验标签等待明确指标规则；追踪标签暂不自动触发。浏览器危险提示缺少截图，不能归因或宣称解决。退回更正导致整个浏览器页面关闭尚未复现；现有撤回／更正流程有回归测试，本轮加入保存状态与离开提醒，但不宣称解决未知的浏览器关闭原因。

测试采用隔离SQLite和模拟浏览器请求；迁移已验证可重复执行及旧行保留。部署脚本通过语法检查，尚未在医院服务器或独立MySQL容器执行本轮升级演练。
