## 生成五家分中心邀请码

更新完成后在服务器运行。输入已有的主中心管理员用户名，不是服务器用户名；不需要提供其密码：

```bash
umask 077
read -r -p '主中心管理员用户名：' EDC_ADMIN_USERNAME
EDC_INVITE_FILE=$(mktemp /root/edc-branch-invites.XXXXXX.tsv)
docker exec edc-prod-backend python scripts/provision_branch_invites.py \
  --admin-username "$EDC_ADMIN_USERNAME" > "$EDC_INVITE_FILE"
cat "$EDC_INVITE_FILE"
```

为南开大学附属医院、天津市津南医院、天津市津南中医院、蓟州区人民医院、天津北大医疗海洋石油医院各生成一个研究者邀请码。人员在登录页点“立即注册”，输入本院邀请码、姓名及自己设置的用户名密码即可注册；权限绑定本院。一人一码，有效期7天（输出到期时间为 UTC，北京时间加8小时）。不要把包含邀请码的文件提交到 GitHub 或发到公开群。

未使用且有效的邀请码会复用，已经使用或过期后重跑可生成新码。医院名称/编号冲突或医院停用时整体停止，不自动改名、合并中心或重置账号。若明确需要分中心管理员，把命令末尾加 `--role center_admin`，该角色可以管理本院邀请码；默认只授予录入权限。

此工具须在医院服务器执行后才会产生线上邀请码，本地开发不会创建线上账号。
